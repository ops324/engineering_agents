## 問い

[contingency_absorbent_design.md](../ssos_eclss_loop/contingency_absorbent_design.md) は
独立監査の S1 で落ちた。**監査が示した修正方向は「未来の不確かさではなくコミットメント構造」**で、
候補を4つ挙げた（投入速度の上限 / 遅延 / 最小投入単位 / 別用途）。
**そのうちどれが実際に判断を作るか。設計文書を書き直す前に測る。**

**方法は監査官のものを再利用した**（`scratchpad/audit/s1_absorbent.py`）。
定数は repo の実測値（CO₂ 産生 0.0144444 kg/step/人、ARS 定格 0.0625 kg/step、
帯 2.0/8.0、減員は `alive//divisor` でラッチ）。

## ★ 著者のテストに欠陥があり、途中で直した（記録として残す）

初回の政策族は投入量を `max(0, CO₂ − 帯)` としていた。**帯より下では常に 0 になるので、
「早めに少しずつ使う」が族に入らない。** 速度上限を付けても意味を持たず、**全構造が 0/48 になった。**
族を **(トリガ x, 投入率 r)** で張り直して測り直した。**初回の 0/48 は族の欠陥であって結果ではない。**

## 結果

**判定: オラクル（未来を全部見る）が、最良の定数政策を person-steps で上回るか。**
定数側は後知恵に寛容にしてある（セルごとに最良のトリガと率を選ばせる）。

| 構造 | 勝率 | 差の中央値 | 差の最大 | 乗員が動いたセル |
|---|---|---|---|---|
| **V0 構造なし**（元の設計） | **0/48** | 0.0 | 0.0 | — |
| V1 投入速度の上限 0.02 | 20/48 | **0.0** | **1.0** | — |
| **V2 遅延 3 step** | **38/48** | **36.5** | 245.0 | **9/48** |
| V3 最小投入単位 1.0 kg | **0/48** | 0.0 | 0.0 | — |
| V1+V2 | 20/48 | 0.0 | 1.0 | — |

```
★ V0 が 0/48 で監査官の結果を再現している ⇒ 模型は整合している
★ V1 は「勝率 20/48」だが**差の最大が 1 person-step**。**雑音であって判断ではない**
   （勝率だけを見て採用すると誤る。EXP-016「分解能と分散は別」と同じ型）
★ V3 は完全にゼロ

   **乗員1人 ＝ 評価点 12.5点。状況の効果と同オーダー ⇒ 条件F が実測で満たされた**
```

## なぜ遅延だけが効くのか

```
速度上限   「間に合わない」を作るが、**最良の定数は「常に少しずつ流す」で吸収できる**。
          帯に触れる前から一定率で流せば、上限は縛りにならない
遅延      **投入の判断を、必要になる前に下さねばならない。**
          「いま流しても効くのは3 step 後」なので、**3 step 先の状態を予想する必要がある**。
          予想を外すと在庫を捨てるか間に合わないかのどちらかになる
最小単位   量の粒度を粗くするだけ。**いつ決めるかを前倒ししない**
⇒ **判断を作るのは「取り返しのつかなさ」ではなく「先に決めねばならないこと」である。**
```

## 予測と結果

```
予測  速度上限は効く / 遅延も効く / 最小単位は効かない
結果  **速度上限は外れ**（勝つが雑音）。遅延は当たり。最小単位は当たり
```
