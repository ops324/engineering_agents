## 問い

[EXP-037](EXP-037-the-window-question-has-a-cheap-answer.md) が
「**no-op は異常を注入しなくても長い窓で水を失う**」ことを示した。
ならば **新しい物理を足す前に、窓を延ばすだけで判断の場面が生まれるか。**
機構は物理: OGS は水を電気分解して O₂ を作る。回さねば O₂ が減り、回しすぎれば水が減る。

**測定前に宣言した偏りの向き:** 著者は直前に「試す価値がある」と述べており、
**判断が見つかったと結論したい誘因がある。疑うべきは偽陽性。**

## 予測と結果

```

P3  形は 400 → 800 の倍化で生き残る               → **当たり**（EXP-037 の規則を適用）
```

## ★ なぜ判断が生まれないか — 初めて数字になった

```
状況の効果（通常 → WRS 故障）        82.4146 → 32.1615 ＝ **50.25点**
応答の効果（故障下で OGS を最適化）    31.9470 → 32.1615 ＝ **0.21点**
⇒ **状況の効果は、応答の効果の 234倍。**
```

**判断が生まれるには「応答が結果を決める」必要がある。ここでは「状況が結果を決めて」いる。**
故障が起きた時点で乗員はほぼ失われ、**政策をどう振っても取り返せない。**
これは [EXP-019](EXP-019-failure-has-no-ambiguity.md)「故障に対処手段が無い」を、
長い窓と連続量で測り直したものである。**同じ壁の6回目。**

```

EXP-038       **状況が結果を決め、応答が決めない** ← 上5件の共通の言い換え
```

## 含意 — ご提案（異常イベントの注入）について

**「異常を入れるだけ」では判断は生まれない。悪化する。**
異常が結果を決めてしまい、応答に残る余地が 0.21点になるからである。

**ROADMAP が R4 について既に書いていたことが、ここで実測で確認された:**

> リークだけを入れてはいけない。**対処手段とセットでなければ実験にならない**

**⇒ 必要なのは「異常」ではなく「異常 ＋ 効き目のある対処手段」で、
その対処手段の"効かせ方"に幅があること。** 現状の OGS 政策にはその幅が無い（0.21点）。
