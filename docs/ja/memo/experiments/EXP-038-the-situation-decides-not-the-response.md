## 問い

[EXP-037](EXP-037-the-window-question-has-a-cheap-answer.md) が
「**no-op は異常を注入しなくても長い窓で水を失う**」ことを示した。
ならば **新しい物理を足す前に、窓を延ばすだけで判断の場面が生まれるか。**
機構は物理: OGS は水を電気分解して O₂ を作る。回さねば O₂ が減り、回しすぎれば水が減る。

**測定前に宣言した偏りの向き:** 著者は直前に「試す価値がある」と述べており、
**判断が見つかったと結論したい誘因がある。疑うべきは偽陽性。**

## ★ なぜ判断が生まれないか — 数字になった（**ただし初稿の 234倍は誤り。下記で訂正**）

> **⚠ 訂正（独立監査・2026-08-29）。表は小数4桁まで再現されたが、比の出し方が一貫していなかった。**
>
> ```
> 初稿    状況 = max − max = 50.2531 ／ 応答 = max − **2番目に悪い** = 0.2145 → 「234倍」
>        **応答だけ w=0.00 を除外していた。分母と分子で定義が違う**
> 訂正    同じ定義（max − min）を両方に当てる: 応答 = **0.7103** → **70.7倍**
>
> ★ さらに重い — 状況と応答は強く交互作用しており、「主効果」として語れない
>    w=0.15 のとき  状況の効果 = 50.25
>    w=0.00 のとき  状況の効果 = **0.0000**（通常も故障も 31.4512 で完全に同一）
>    通常状況での応答の効果 = 82.4146 − 31.4512 = **50.96点** ← **状況の効果より大きい**
> ⇒ **「結果を決めるのは状況であって応答ではない」は、この表全体については偽。**
>    通常時には応答が全て（乗員 4/4 か 0/4）を決めている
> ```
>
> **正しい言い方: 「飽和域に入ったあとは、この1鍵の応答に 0.71点しか残っていない」。**
> **壁自体は本物**（故障下で 50.25点のうち 0.71点しか取り返せない）。壊れたのは比と一般化。

```
状況の効果（通常 → WRS 故障・w=0.15）  82.4146 → 32.1615 ＝ **50.25点**
応答の効果（故障下・同じ定義で max−min） 31.4512 → 32.1615 ＝ **0.71点**
⇒ **飽和域では、応答に 0.71点しか残っていない（70.7倍）**
```

**判断が生まれるには「応答が結果を決める」必要がある。飽和域では「状況が結果を決めて」いる。**
故障が起きた時点で乗員はほぼ失われ、**政策をどう振っても取り返せない。**
これは [EXP-019](EXP-019-failure-has-no-ambiguity.md)「故障に対処手段が無い」を、
長い窓と連続量で測り直したものである。**同じ壁の6回目。**

```

```

## 含意 — ご提案（異常イベントの注入）について

**「異常を入れるだけ」では判断は生まれない。悪化する。**
異常が結果を決めてしまい、応答に残る余地が 0.21点になるからである。

**ROADMAP が R4 について既に書いていたことが、ここで実測で確認された:**

> リークだけを入れてはいけない。**対処手段とセットでなければ実験にならない**

**⇒ 必要なのは「異常」ではなく「異常 ＋ 効き目のある対処手段」で、
その対処手段の"効かせ方"に幅があること。** 現状の OGS 政策にはその幅が無い（0.21点）。
