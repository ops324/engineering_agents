## 後から分かった条件の欠陥（2026-08-28 追記）

**この実験は、腕の条件が公平でない状態で走っていた。** EXP-014 の準備中に判明した。

LLM 腕は **WRS（水回収）の存在を知らされていなかった。** `_ECLSS_OPERATIONAL_LEVERS` に
`water_recovery` が無く、ペルソナも「ARS と OGS を coordinate せよ」としか言っていない。
さらに観測文字列に `urine_buffer_l` が無く、**ルール腕が WRS の起動判断に使っている読み値
そのものが見えていなかった**。

```
ref_labeled_rule_base   ARS 37 / OGS 3 / WRS 30 回   ← 3系統を操作
llm 24本すべて          water_recovery ……… 0 回     ← 一度も出していない
```

つまりこの実験が測ったのは「AI はルールより上手いか」ではなく、
**「2系統しか知らされていない AI は、3系統を全部知っているルールより上手いか」**である。

### ただし、結論は覆らなかった

EXP-014 で levers と `urine_buffer_l` を開示して測り直した（世代 v4、n=24）:

```
LLM は WRS を使うようになった       0/24 本 → 12/24 本（総 122 回）
しかし得点への効果は無い            使用 68.859 対 非使用 69.159、p = 0.864
                                    （全滅を招いた request_o2 使用6本を除いた 18本で検定）
主結果                              ルール 82.199 対 LLM 61.487、差 −20.71、p = 0.00001
                                    LLM 対 no-op は差 −7.18、p = 0.060 で区別できない
```

**格差は実在したが、主因ではなかった。** 水はこの運用点の律速ではない（余裕 1.50倍）ため、
WRS を教えても成績は動かない。**したがって下の結論はそのまま有効**である。
ただし「AI はルールに劣る」と引用する際は、**v3 では腕の条件が公平でなかった**ことを添えること。

詳細: [EXP-014](EXP-014-llm-vs-rule-v4.md)

## 問い

**運用者として、AI はルールより上手いのか。** この研究の本題である。

これまでに分かっていること:

```
labeled_rule_base（決定的）  200 person-steps
llm 21本（EXP-011+012）      平均 174.1、SD 18.3、うち 8本が 164 に着地
none（決定的）              164
```

平均だけ見れば AI は劣る。しかし **21本中8本が「何もしないのと同じ」に着地**しており、
「常に少し下手」なのか「時々まったく機能しない」なのかで意味がまるで違う。**そこを分ける。**

## 解析方法（結果を見る前に固定する）

- 主指標: **person-steps**、ゲート合格 run のみ
- 検定: ルール腕は**決定的なので定数**（200）。**1標本 t 検定・両側・α=0.05** で AI 腕の平均を 200 と比較
- **分布を必ず出す**（平均だけにしない）。164 に一致した本数を数える
- **行動側**: 適用された `air_revitalisation` の回数と person-steps の **Pearson 相関**（n と 95%CI つき）
- 164 群とそれ以外で ARS 発行回数を比較する
- 副指標として peak CO₂ / o2_steps_below / 生存者 / 拒否率を報告する（判断には使わない）

## 予測

| # | 予測 |
|---|---|
| P1 | AI 腕の平均は 200 より**有意に低い**（p<0.05） |
| P2 | 分布は二峰のまま。**164 ちょうどに着地する run が 24本中 5〜10本** |
| P3 | 164 に着地した run は **ARS 発行がゼロまたは極少**（1回以下） |
| P4 | ARS 発行回数と person-steps に**正の相関**がある（r > 0.5） |
| P5 | ゲート不合格が 24本中 **2〜7本**（EXP-012 は 3/14 = 21%） |

**P3 と P4 が当たれば、「AI が劣る理由は ARS を動かさないことだ」と言える。**
外れれば、原因は別のところにある。

## 追記（走行中、2026-08-26）— この実験が答えられること・答えられないこと

バッチ開始後にスコアカードを実装し（`16b2b2a`）、**主指標の選択に問題があったと分かった。**

- スコアカードの主軸は **50 × 残存 ÷ 初期**（終了時の人数）であり、**person-steps は載っていない**
- 主軸で 10% の効果を検出するには **198 run/arm ≒ 26時間**（乗員4では5段階しか取れず CV 35.2%）
- person-steps は 18 run/arm ≒ 2.4時間（CV 10.5%）

**予測は書き換えない**（事前登録の意味が消えるため）。この実験は当初の計画どおり
person-steps で検定する。そのうえで**答えられる範囲を正直に述べる**:

| | |
|---|---|
| 答えられる | AI腕はルール腕より person-steps が低いか。**なぜ低いのか**（P3・P4 の行動側の予測） |
| 答えられる | スコアカードの材料一式（A軸の曝露・帯滞在、C軸の遅延、D軸の要求/実処理比） |
| **答えられない** | **スコアカードの主軸で何点差か。** 24本では足りない（198本必要） |

person-steps は**スコアカード外の代用指標**として報告する。主軸を置き換えたわけではない。

## 結果

24 run + 決定的な参照2本。1本 297–567 秒、合計約3時間。**24本中1本がゲート不合格**（`llm_r12`、capacity_bounds）。

### 主解析 — person-steps（事前登録: 1標本 t 検定・両側・α=0.05、ルール腕は定数 200）

```
LLM 腕  n=23  mean 176.09  SD 22.38
ルール腕 200 との差 -23.91   95%CI [-33.59, -14.23]
t = -5.123, df = 22, p = 0.000039  → 有意
```

**ルール腕の方が有意に優れている。**

### スコアカードでの採点

全 run が持つ3軸（残存50 + A20 + B20 = 90点満点）で比較する。C・D は actor 操作のある run にしか無い。

**この節の数字はすべて `habitat 388 m³`（NASA-STD-3001 の ppCO₂ 限界）の物差しで採点している。**
`run 自身の閾値`で採点すると ルール 82.20 / no-op 68.67 / LLM 64.07 になる。
他の実験と比べるときは物差しを揃えること（EXP-014 で一度取り違えた）。

```
ルール腕（決定的）   84.31 / 90
no-op 腕（決定的）   69.38 / 90
LLM 腕 (n=23)       65.25 / 90   SD 16.09   range 24.7 - 85.5

  対 ルール腕   差 -19.06   95%CI [-26.02, -12.10]   p = 0.00001   → 有意
  対 no-op 腕   差  -4.12   95%CI [-11.08,  +2.84]   p = 0.232     → 有意でない
```

**LLM 腕は、何もしない腕と統計的に区別できない。** 平均は下回っているが有意ではない。

> **⚠ 窓の但し書き（2026-08-29・[EXP-031](EXP-031-the-second-headline-was-the-window.md)）**
>
> **「LLM 腕は no-op と区別できない」は、観測窓 50 を選んだことの産物である。**
> 同じ run を窓 W で切り直すと結論が一周する:
>
> ```
> 生存者数、LLM vs no-op        W=15                 W=50
>   v3   3.708  p<1e-5 **良い**   2.458  p=0.050
>   v4   3.458  p=0.0002 **良い** 2.500  p=0.049 **悪い**
>   v5   3.583  p=0.00001 **良い** 2.792  p=0.170 区別できない
> ```
>
> 機構: **LLM 腕は早く撃ち、続かない**（v5 で 24本中10本が step 13 より前に ARS。
> ルール腕は step 13）。50 step で切ると「続かない」が、15 step で切ると「早い」が支配する。
> **どちらも本当で、窓がどちらを見せるかを決めている。**
>
> **「ルール腕が LLM 腕に有意に優位」のほうは無傷**（W≥15 の全窓・3世代すべてで有意）。
> **公表値の絶対水準も打ち切られたカウントである** — ルール腕自身が step 887〜894 に
> 水で全員を失い、共通3軸は 82.44 → 32.57 に落ちる。

**ルール腕だけが、両者より明確に優れている。**

```
23本の分布（90点満点）
  24.7  30.0  46.7  46.8  49.7  61.9  62.2   ← no-op（69.38）を下回った 7本
  69.4 ×5  69.5 ×3  70.0 ×2  70.6  71.7
  84.8  85.4  85.5  85.5                     ← ルール腕（84.31）以上の 4本
```

**7本は何もしないより悪く、4本はルール腕と同等以上。** 平均は分布の形を隠す。

### 差がどこから来ているか

```
軸               ルール腕   LLM平均    差
残存 (50)          50.0     32.07   +17.93   ← ほぼ全部ここ
A 生存環境 (20)     20.0     19.79    +0.21
B 資源余裕 (20)     14.3     13.40    +0.91
C 判断 (5)          4.99      2.62    +2.37
D 応答 (5)          5.00      5.00     0.00   ← 装置は常に満点（EXP-012 の予想どおり）
```

**差は「乗員が死ぬこと」と「判断」に集中している。** 環境（A）はほぼ動かない — この運用点は
絶対基準で見て CO₂ 的にぬるい、という EXP-012 の観察と整合する。

### 予測の答え合わせ（5件中 2件的中）

| # | 予測 | 実測 | |
|---|---|---|---|
| P1 | LLM 腕の平均は 200 より有意に低い | **p = 0.000039** | ✓ |
| P2 | 164 ちょうどが 24本中 5〜10本 | **6本**（ほかに 200 ちょうどが4本） | ✓ |
| P3 | 164 群は ARS 発行 0〜1回 | 6本中5本が **0回**、1本が **6回** | ✗ |
| P4 | ARS 発行回数と person-steps に r>0.5 | **r = 0.421**（95%CI [0.011, 0.710], p=0.045） | ✗ |
| P5 | ゲート不合格が 2〜7本 | **1本** | ✗ |

### P3 の外れ方が重要 — 逆向きには完全に成立する

```
ARS 発行 0回の run  5本 → person-steps は 全部きっかり 164（no-op と同値）
ARS 発行 1回以上    18本 → 平均 179.4
  差 +15.4  95%CI [+3.3, +27.6]  t=2.69, p=0.0155
```

**「スクラバーを一度も動かさなければ、必ず何もしないのと同じ結果になる」は 5/5 で成立する。**
逆は成立しない（`llm_r19` は ARS を6回出しながら 164 に着地した）。

### そして、動かしても足りない

```
ARS を1回以上出した 18本だけをルール腕と比べる
  mean 179.44   差 -20.56   95%CI [-32.67, -8.44]   p = 0.0023  → 有意
```

**「AI が劣るのは、時々何もしないから」だけではない。操作していても劣る。**
これは EXP-012 の時点では区別できていなかった。

### P4 の外れ方 — 関係は線形ではない

```
ARS 発行回数 → person-steps
   0回 → 164（5本すべて）
  10回 → 200        20回 → 200        23回 → 200
  36回 → 196        70回 → 188
```

**数回で足りる。それ以上出しても改善しない**（70回出した run は 188）。閾値的な関係なので
Pearson は過小評価する。r=0.421 の 95%CI は [0.011, 0.710] と広く、**0 をかろうじて外れている**程度。

## 結論

- **ルール腕が勝つ。** スコアカードの共通3軸で 84.31 対 65.25（p=0.00001）
- **LLM 腕は「何もしない」と区別できない**（p=0.23）。平均は下回るが有意ではない
- **差の出所は乗員の死と判断であって、環境の悪化ではない**
- **失敗は2種類ある**: 一度もスクラバーを動かさない（5/23、必ず no-op と同値）と、
  動かしても足りない（18本の平均でもルール腕に有意に劣る）
- **装置側（D軸）は完璧**。このシミュレータでは装置が失敗しないので、差は全部運用側にある

### この結果の限界

- **腕の条件が公平でなかった**（2026-08-28 判明。上の追記を参照）。LLM 腕は WRS を知らされておらず、
  24本すべてで一度も使っていない。EXP-014 で是正して測り直した結果、**結論自体は覆らなかった**
- **世代 v3 の結果である。** 定格超過の欠陥（ARS が定格の4倍で回る）を抱えたままの物理での比較。
  修正後（[rated_capacity_invariant.md](../ssos_eclss_loop/rated_capacity_invariant.md)）は取り直しになる
- 主軸（終了時の残存率）そのもので有意差を出すには 198本必要。ここでは共通3軸の合計と person-steps で判定した
- LLM は1モデル1温度（qwen3.5-9b、0.45）のみ。プロンプトも1種類
