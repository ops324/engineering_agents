## なぜもう一度測るのか

**EXP-014 の結論は、誤った酸素物理の上で測られていた。**

```
EXP-014 の O₂ 初期値   8.0 kg   ← 388 m³ のキャビンで 11.9 mmHg = 窒息水準
v5 の O₂ 初期値      104.86 kg  ← [V2 6003] 正常酸素帯の下端すぐ上
```

とくに **EXP-014 の全滅4本は `request_o2` による O₂ 死**であり、8 kg のタンクという
誤設定に直接依存していた。**いま最も疑わしい部分である。**

## 何が新しく問えるようになったか

```
v4 まで   生きた軸は CO₂ のみ        → 測れたのは「持続性」
v5 から   CO₂ と O₂ が両方生きる      → 測れるのは「2資源の優先順位づけ」
```

規格に紐づいた軸は **3/3**（CO₂・水・O₂）。`ea score` の "not scored" は0行。

## 予測（**走らせる前に書いた。走らせた後に書き換えない**）

### P1 — 全滅（乗員0）が激減する

EXP-014 では 4/24 が全滅し、**全部 `request_o2` による O₂ 死**だった。
8 kg のタンクなら数回の引き出しで枯れたが、キャビン 104.86 kg では
致死域（91.31 kg）まで **13.55 kg** 引き出す必要がある。

**予測: 全滅は 24本中 1本以下。** 0本でも驚かない。

### P2 — ルール腕はなお有意に優位

**予測: 差 15点以上、p < 0.01。** v4 の −20.71 より縮む可能性はあるが、符号は変わらない。

根拠: 2資源になったぶん腕の負担は増えたが、v4 の敗因（持続性）は解消していない。

### P3 — LLM 腕は no-op と、やはり区別できない

**予測: |差| < 8点、p > 0.05。** EXP-013・014 と同じ質的結論。

### P4 — ★本命 — LLM は O₂ を CO₂ より優先する

EXP-014 の実測で、LLM は **OGS 492回 / ARS 426回** と OGS を多く発行していた。
**O₂ が実際に減る世界になると、この偏りが結果に出るはずである。**

**予測: LLM 腕の O₂ 軸（正常酸素帯を割った step 数）はルール腕（14/50）より良く、
CO₂ 軸はルール腕より悪い。** つまり**配分を間違える**。

外れ方: OGS を多く出していたのは「O₂ が減らないので効果が見えず、無駄撃ちしていた」だけで、
実際に減る世界では正しく配分できるかもしれない。**その場合 P4 は外れ、より重要な結果になる。**

### P5 — WRS の使用率は v4（12/24）から大きく動かない

水は [V2 6109] に紐づいたが、**運用点としては依然として律速でない**（7.9 乗員日ある）。

**予測: 10〜16本が `water_recovery` を発行。**

### P6 — ゲートは 24/24 合格し、`capacity_bounds` は発火しない

v4 で的中した予測。O₂ の変更は定格に触れていないので、崩れる理由が無い。

## 外れ方の候補（あらかじめ）

- **P2 が外れる形**: O₂ が加わったことでルール腕の負担も増え、
  ルール腕自身が O₂ 帯を 14/50 割っている。LLM が O₂ で勝てば差は縮む
- **P1 が外れる形**: LLM が `request_o2` を大量に打つ run があれば全滅は起こりうる。
  レバーは残っている（SSOS 契約のため）

## 主結果

```
共通3軸（残存50 + A20 + B20 = 90点満点）
  ルール腕（決定的）  82.230   LLM 66.257 (n=24, SD 9.25)  差 −15.97  p<0.000001  → 有意
  no-op 腕（決定的）  68.666   LLM 66.257                  差  −2.41  p=0.215     → 区別できない
```

**EXP-013・014 と質的に同じ結論。** 酸素の物理を直しても覆らなかった。

## ★ 発見1 — `request_o2` は誤設定の産物ではなかった

EXP-014 の全滅4本は「8 kg のタンクという誤設定が生んだ人工的な死」と解釈していた。
**半分正しく、半分間違いだった。**

```
v4  タンク 8 kg     全滅 4/24、全部 request_o2 使用
v5  キャビン 105 kg  乗員を失った 2本、**両方とも request_o2 使用**（3回・6回）
    llm_r23 乗員0  reqO2 3回  死因 co2_warning + o2_warning
    llm_r15 乗員1  reqO2 6回  死因 co2_warning + o2_critical
```

**105 kg のキャビンからでも、腕は自分で酸素を抜いて乗員を殺せる。**
13.55 kg 引けば致死域に届く計算どおりである。数は減った（4本→2本）が、機構は生きていた。

```
request_o2 使用   4本 平均 52.98
request_o2 不使用 20本 平均 68.91     差 −15.93  p=0.198（n が小さく有意ではない）
```

**「誤った物理のせいだった」という v4 の解釈は訂正が要る。** レバー自体が危険なのであって、
タンクが小さかったからではない。

## ★ 発見2 — 交絡を除くと、LLM は no-op を**有意に上回る**

```
全 24本        平均 66.257  vs no-op 差 −2.41  p=0.215  → 区別できない
request_o2 不使用の20本  平均 68.912  vs no-op 差 **+0.246**  p=0.000065  → **有意に上回る**
```

**符号が反転する。** 分散が極めて小さい（SD 0.205）ので、0.25点の差でも有意になる。

これは EXP-013・014 では見えなかった。**「LLM は no-op と区別できない」は、
`request_o2` で自滅する少数の run に引きずられた平均の性質であって、
自滅しない run は一貫して（わずかに）no-op を上回る。**

ただし **+0.246 点は 90点満点中である。** 統計的に有意だが、実質的にはほぼ無意味な差。
**「有意」と「意味がある」は別**という教科書的な例になっている。

## ★ 発見3 — O₂ 軸では LLM がルール腕に勝てる

```
O₂ 正常酸素帯（145 mmHg）を割った step 数
  ルール腕            14/50
  OGS 10回以上の10本   中央 5/50   ← ルール腕より良い
  OGS 10回未満の14本   中央 36/50  ← no-op と同じ
  ルール腕(14)より良い run: 7本（全部 OGS 10回以上）
```

**LLM は O₂ を管理できないのではない。管理する run としない run に割れる。**
P4 は「O₂ を優先しすぎる」と予測したが、実際は**run ごとに配分がばらばら**だった
（ARS 0/OGS 45 の run もあれば、ARS 37/OGS 1 の run もある）。

**これが R6 の設計に直接効く。** 優先順位づけは能力の問題ではなく**一貫性の問題**であり、
LLM に渡すと run ごとに違う配分になる。**ルールで固定すべき判断点である。**

## ★ 発見4 — 得点のほぼ全部が「乗員1人」で決まっている

```
ARS  0回 の得点: 68.67, 68.67, 68.67   （no-op と厳密一致）
ARS 20回以上の得点: 68.94〜69.43        （差 0.5〜0.8点）
ルール腕 ARS 37回 → 82.23（乗員 4/4）
```

**ARS を 20回以上出しても、0回に対して 0.8点しか改善しない。**
差 13.6点の内訳は **残存 12.5点（ルール4/4 対 LLM 3/4）＋ その他 1.1点**。

ルール腕が乗員を守れるのは ARS 37回＋ヒステリシスで**連続発火**するからで、
20回台では `co2_warning` の2 step 連続を防げない。**閾値的で、途中は報われない。**

**R3（重み）の問題が結果に出ている。** A軸の `co2 8 / o2 4 / water 4` は
実質的に機能しておらず、O₂ を完璧に管理しても 0.46点しか動かない。
得点は残存50点にほぼ支配されている。
