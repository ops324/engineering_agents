## ★ 見出し② 「LLM 腕は no-op と区別できない」 — **窓 50 を選んだことの産物**

**同じ run・同じ指標で、窓を動かすと結論が一周する:**

```
生存者数、LLM vs no-op（no-op は3世代とも 3人）
世代      W=15                W=20              W=40         W=50
v3   3.708  p<1e-5 良    3.708  p<1e-5 良    3.042 p=0.873   2.458 p=0.050
v4   3.458  p=0.0002 良  3.167 p=0.043 良   2.542 p=0.069   2.500 **p=0.049 悪**
v5   3.583  p=0.00001 良 3.167 p=0.043 良   2.875 p=0.328   2.792 p=0.170
```

**W=15 では3世代すべてで LLM 腕が no-op より有意に「良い」。
W=50 では「区別できない」（v3/v5）か、有意に「悪い」（v4）。**

**誰も 50 を正当化していない。** scenario.yaml は `steps: 50  # [-] default observation steps` と
書いているだけである。第二の見出しは、その既定値の関数だった。

### 機構 — LLM 腕は no-op と同じことをしているのではない

```
初回 ARS の step（v5・26 run）
  ルール腕   13（帯を割ってから撃つ）
  no-op     撃たない
  LLM 腕    4, 5, 6, 6, 7, 7, 7, 8, 9, 12 ... **24本中10本が step 13 より前に撃つ**
```

**LLM 腕は早く撃ち、続かない。** ルール腕は遅く撃ち、続ける。
50 step で切ると「続かない」ほうが支配的になり、15 step で切ると「早い」ほうが支配的になる。
**どちらも本当で、窓がどちらを見せるかを決めている。**

**800 → 1600 に倍にしていれば必ず見えた。倍にするのを、答えが安全なところでちょうど止めていた。**

## 監査を鵜呑みにしなかった点（1件）

監査は「打ち切りの成分が構造的にゼロの指標」として
**初回死亡（step 14）より前の区間の CO₂ 曝露積分**を提案し、
「ルール 0.000 < LLM 0.021 < no-op 0.051 が3世代とも p≤0.0002」と報告した。

**再現したら順位が違った。** 原因は telemetry の行の取り方である:

```
ルール腕の初回 ARS は step 13 ＝ 窓 0-13 の**最後の step**
  pre 行（行動前）  ルール 0.0511 = no-op 0.0511 > LLM 0.0298  → **LLM が最良**
  post 行（行動後） ルール 0.0000 < LLM 0.0213 < no-op 0.0511  → 監査の報告どおり
```

**差の全部が窓の端の1 step から来ており、行の選択で順位が反転する。**
ただし **W=20 まで広げると両方の取り方で `ルール < LLM < no-op` が安定する**
（pre: 0.2586 / 0.7624 / 1.3544、post: 0.0000 / 0.6891 / 1.3544）。

**⇒ 監査の結論（順位は本物）は支持されるが、監査が選んだ W=14 は脆い。**
この指標を使うなら W≥20 で取ること。
