## ★★ 発見2 — 設計の表に誤りが2件ある（着手前に直すこと）

`ROADMAP.md` の R4 設計は次の表を持つ。**漏れ量そのものは自己整合している**:

```
直径 1.0 mm →  10.1 kg/day     係数 q/d² = 10.10
直径 1.6 mm →  25.8 kg/day     係数 q/d² = 10.08     ⇒ 漏れ(d) = 10.08 × d²（3点とも整合）
直径 4.1 mm → 169.2 kg/day     係数 q/d² = 10.07
```

**OGS の余力 5.89 kg/day も正しい**（`scenario.yaml`: 定格 9.25 − 乗員4の需要 0.84×4 = 3.36）。

**だが2つの判定が誤っている:**

```
誤り1  「支えられるリーク上限は直径 **1.58 mm**」
       → 余力 5.89 を漏れ(d)=10.08d² に当てると **d = 0.764 mm**。**2.08倍のずれ**
       ★ 正体: **1.587 mm は「窓50 内で致死帯 91.31 に届く直径」**である。
         （必要な正味の減り (104.86−91.31)/0.6944日 = 19.51 kg/day ＋ 余力 5.89 = 25.40 → d=1.587）
         **設計は「支えられる上限」と「支えられず死ぬ下限」を取り違えている。意味が逆である**
誤り2  表の1行目「直径 1.0 mm / 10.1 kg/day / ✅ OGS を回し続ければ支えられる」
       → **10.1 > 5.89。支えられない。** 判定が自分の数字と矛盾している
```

## ★★★ 発見3 — 判断が起きる帯は、いまの計器に1ミリも映らない

上の訂正から、窓50 での結末は3つに分かれる:

```
 d < 0.764 mm          OGS が完全に補える。O2 は動かない        → 判断は無い（定数「回す」）
 0.764 < d < 1.587 mm  漏れが余力を上回るが、**窓内では致死帯に届かない**  ← **ここが R4 の狙う帯**
 d > 1.587 mm          **窓内で全滅**（OGS 全開でも）             → 判断は無い（定数「塞ぐ」）
```

**その中間帯が採点に映るかを実測した**（初期O2 を下げて O2 軌跡の低さを模擬・窓50・決定的）:

```
初期O2    共通3軸    B軸     B.o2_worst   乗員
104.86   82.2297   12.238    3.000       4     ← 既定
103.00   82.2297   12.238    3.000       4
101.95   82.2297   12.238    3.000       4     ← 直径 1.0 mm の窓末に相当
 99.00   82.2297   12.238    3.000       4
 97.12   82.2297   12.238    3.000       4     ← 直径 1.3 mm 相当
 95.00   82.2297   12.238    3.000       4
 93.00   82.2297   12.238    3.000       4
 91.48   82.2292   12.237    2.999       4     ← 直径 1.58 mm 相当（差 0.0005）
 91.32   30.2473   12.496    2.996       0     ← 帯を割った瞬間に全滅
```

**⇒ 初期O2 を 104.86 → 93.00 まで、11.86 kg 下げても共通3軸は小数4桁まで同一。**
**O2 の余裕を測る軸（B.o2_worst）は 3.000 の満点に張り付いたまま動かない。**

**⇒ R4 の中間帯（0.764〜1.587 mm）は、この計器では完全に不可視である。**
**見えるのは「帯を割ったか」の二値だけで、割れば全滅する。**

## 判定 — **R4 は現状の計器のままでは S1 を通らない**

```
帯の下  何も起きない（採点が動かない）
帯の中  **採点が動かない**（実測）
帯の上  全滅 ⇒ 「即座に塞ぐ」が支配的
⇒ 形は「崖と崖」。**EXP-017 f（撃つのは無料 → 常に撃つのが最適）と同じ退化**である
  塞ぐのが無料である限り、漏れの大きさを診断する価値は生まれない
```

**R4 を成立させるには、少なくとも次の2つが**要る（設計の判断点②が既に名指ししていた）:

```
① 補修に代償を与える  無料なら「常に即座に塞ぐ」が定数として勝つ
② 帯を割る前の結末が採点に映ること  いまは映らない
```

## ⚠⚠ ②について — **ここは物差しのハザードそのものである**

**「軸が動かない → 採点を変える」は、この枝が3回間違えた形である**（EXP-016 / EXP-020 / EXP-023）。
**本実験は事実の報告に留め、採点式を1文字も変えていない。**

そして EXP-023 が記録している: **「飽和は免疫でもあった」** —
O2 軸が飽和しているおかげで、初期O2 を動かす攻撃が点を動かせない。
**②を触るなら、その免疫を失う。独立監査を通すこと。**
