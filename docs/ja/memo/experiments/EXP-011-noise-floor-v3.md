## なぜやり直すか

EXP-001 は**乗員50・survival 無し・古い閾値**の運用点で、指標は `peak_co2` だった。EXP-007〜009 で
運用点が変わり（乗員4）、判別に効く指標も変わった（person-steps / exposure）。**必要 n を出し直す。**

`design=none` とするのは、事後設計エージェント（:8001 の 27B、別モデル）を回路から外して
**actor 側のばらつきだけを測る**ため。

### P5 を外した理由

「乗員4×50 step は離散的だから取りうる値が少ない」と考えたが、**死亡する step が run ごとに違う**ので
積分値は連続的に散る。値の粒度ではなく**タイミングの自由度**を見落としていた。

### P3 は棄却だが、逆向きの主張も立たない

```
分散比 var(t00)/var(t045)     F(4,4) の 5% 臨界値は 6.39
  person-steps     0.82   → 差は言えない
  peak CO2         2.12   → 差は言えない
  exposure        16.78   → 臨界値超え。ただし exposure は 5 run 中 3 run が 0 で、
                            F 検定の前提（正規性）が壊れている指標なので信用できない
```

**「temperature 0.45 の方がばらつく」は棄却された。「0.0 の方がばらつく」は立証されていない。**

### P2 を外した理由 — O₂ 軸が生きた

`t00_r4` の死因は **`o2_warning` 3名**。EXP-009 は「乗員4では判別は CO₂ 軸だけから来る」と結論したが、
それは**決定的な腕での話**だった。LLM 腕は OGS を適時に回さないことがあり、そのとき O₂ が LOW 帯に居座って
2 step ごとに 1 名ずつ失われる。**シナリオは EXP-009 が示したより分解能がある。**

（この run は peak CO₂ が 2.050 kg = 10本中最良でありながら、生存者は最少の 1 名だった。
**CO₂ だけ見ていると正反対の評価になる。**）

## 予測していなかった観察（要検証）

```
person-steps     labeled_rule_base（決定的）  200
                 llm t=0.45                185.8 ± 11.9   (172–200)
                 llm t=0.0                 168.8 ± 10.7   (164–188)
                 none（決定的）              164
```

**temperature 0.0 の LLM 腕は、何もしない腕（164）とほぼ変わらない。** 0.45 はルール腕に近い。
Welch t = 2.37（df≈8、p≈0.045）だが、**事後的な比較であり n=5**。**現時点では仮説**。

ただし今回得た必要 n（約7/arm）により、**この仮説は 7+7 run ≒ 2 時間で検証できる。**

## 結論

- **主軸を person-steps にすると、必要 n は約 7/arm。** 実験が現実的な規模になった
- **temperature 0.0 は決定性を与えない**（EXP-002 の結論が新運用点でも成立）。同一 seed でも 5/5 が異なる
- **exposure は指標として使えない**（CV 155%、必要 n 約3800）
- LLM 腕は O₂ 軸を活性化させる。決定的な腕だけでは見えなかった

## 後日追記（2026-08-26）— この発見を評価層に反映した

`t00_r4`（CO₂ 最良・生存者最少）を受けて、**O₂ と水を比較指標に追加**した（`inventory_metrics`）。
標準では採点できない軸なので、**凍結したサバイバル帯**に対する「下回った深さと長さ」を測る。
`ea score` も両軸を必ず表示する（「標準では採点できない」と明示したうえで）。

効果の実演（OGS の起動閾値を 6.0 → 3.0 に下げる提案、初期 O₂ 6.5 kg・50 step・故障あり）:

```
  exposure_integral   -4.031  改善      ← CO₂ 側はすべて「改善」
  peak_kg             -0.202  改善
  terminal_margin     +0.126  改善
  water_min_l         +0.528  改善
  o2_steps_below      +7.000  悪化      ← O₂ 側だけが悪化
  o2_min_kg           -0.082  悪化
  verdict: mixed（4改善 / 2悪化）

  control  乗員 0 人  死因 co2_warning 1 + o2_warning 3
  treated  乗員 0 人  死因 o2_warning 4
```

**CO₂ だけで採点していれば、この提案は「改善」と判定されていた。**
しかも CO₂ が改善した理由は**乗員が早く死んだから**である（人が減れば CO₂ 生成も減る）。
単一軸の採点は、この倒錯を検出できない。
