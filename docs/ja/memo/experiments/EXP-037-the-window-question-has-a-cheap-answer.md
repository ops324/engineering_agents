## 問い

[STATE](STATE.md) は「案3 の成否は**観測窓に依存しない指標で測り直すまで保留**」とし、
さらに「person-steps も打ち切りに強くない。**指標選びからやり直す**」と書いて止まっていた。
**異常イベント（O₂・水のピンチ）を設計する前に、この宿題を片付ける必要がある** —
指標が決まらないまま測れば [EXP-030](EXP-030-the-window-was-cutting-the-ending.md) の失敗を繰り返す。

## 予測（測定前にコミット）と結果

```

      長い窓では残存50点が全腕でゼロになる。ゆえに「生存」ではなく「どれだけ持ったか」が指標になる
結果  **外れ。** ルール腕は 400 step でも **4/4 のまま**で、点も 82.08〜82.41 に収まる
```

## ★ 宿題への答え — 「窓に依存しない指標」を探す必要はなかった

**指標を替えるのではなく、指標が窓に対して安定しているかを確かめればよい。**

```
規則（提案）  **結論は、観測窓を倍にしても生き残ったときだけ採用する。**
            倍にして結論が変わるなら、それは打ち切りの産物である

この規則が EXP-030 で発火したか  **する。** 案3 の運用点は steps=100 で全滅していた
この規則が公表値を落とすか       **落とさない。** ルール腕は 50→400 で 0.34点しか動かない
費用                          決定的な腕なら 1 run 0.1秒。**倍にする検査はほぼ無料**
```

**EXP-032 の「窓を 20〜144 に振っても分解能は増えない」は誤りではない** — あれは
**生存者数（0〜4の5段階）**で測っており、そこでは確かに「4 対 3」のままだった。
**連続量の共通3軸で見ると、同じ区間で差は広がっている。**
⇒ **粗い指標が窓の効果を隠していた。** EXP-030 の「生存者数は打ち切りカウント」と同じ型。

## 含意

```
① 公表値 82.2297 は**窓 50 の産物ではない**（8倍にして 0.34点）。窓に根拠が無いことは変わらないが、
   **結論はその選択に依存していなかった**。これは EXP-032 が確かめ損ねていた側面
② 異常イベントの設計に進んでよい。**判定規則は「窓を倍にして生き残るか」**
③ no-op が 400 step で 0/4 になる機構は**水**（74.90 → 49.82 L・帯 50.0）。
   ⇒ **水のピンチは、異常を注入しなくても長い窓で自然に現れる。**
     異常イベントの設計は「新しい物理」ではなく「窓の長さ」から始められる可能性がある
```
