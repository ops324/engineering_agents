## 守られたもの

監査1が全 PlantState フィールドの書き込み元を列挙して**収支3本を独立導出**。
12本×60step + 3本×2000step のランダム駆動で検証。

- 収支3本すべて正しい（残差 carbon 4.9e-15 / oxygen 2.4e-15 / water 2.9e-13）
- 意図的な除外2項も正しい（戻すと 0.1 L / 41 L 破綻）
- 量論恒等式3本、ARS 保存則論証、許容誤差、control アームの隔離 — すべて妥当

## 見つかった主要欠陥（修正済み）

1. **軌道指標が step ではなく telemetry の行を数えていた** — 3監査すべてが独立に発見。
   40step の run で `longest_streak=53`。物理軌跡がビット単位で同一なのに「曝露37%改善」を実演された
2. **`capacity_bounds` が未実装** — `initial_co2_mass: 1800` で定格1000倍を購入、full form で通過
3. **水素収支が欠落かつ未申告** — 追加した瞬間に自分のテストフィクスチャの物理的不整合を検出
4. **収支8項を削除してもテストが緑** — `PlantModel` 駆動 fixture で 8/8 検出に改善
5. 破損測定値がゲートをクラッシュ／`peak_kg` 未比較／世代跨ぎの物差し漂流／mock は 9項目中7項目が常にスキップ／CLI の契約違反3件

## 過大主張の訂正

| 述べたこと | 正しくは |
|---|---|
| 411 run で収支が 1e-15 で閉じる | **24 run のみ**評価。最悪残差は水の 8.0e-14 |
| 同一/seed間 = 0.78、seedはほぼ何も固定しない | 比 0.821、F=1.48(9,7)、**p≈0.6**。立証できない |
| CV 26% | n=5、95%CI [16%, 76%]、結果は二峰性で CV は不適切 |
| 超過step数なら 68 run/arm | **退化**（3mmHg帯では step 0 から超過＝実質行数） |
| 0/270 critical | 終端のみ。30/270 が途中で通過 |
| 61.3 m³ でぴったり一致 | 逆算による**循環論法** |
| `input_water_mass` は不変 | **OGS が動いていない null 実験**だった |

## 未修正

- 許可7ターゲット中3つが死んでいる（`merge_labeled_policy_from_thresholds` が後から上書き）
- probe が `design_llm` を検査しない／`prefer_config` を無視

監査2・3 を誤ったブランチに向けた（監査1は自力で検出）。

## 教訓

**監査は機能した。** 物理は健全だったが、その上の測定層は監査前は信頼できなかった。
節目で独立監査を入れること。数字を述べるときは n と不確かさを添えること。
